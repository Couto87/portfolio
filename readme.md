# Portfólio de Claudio Couto

Site estático com 30 projetos independentes, preparado para publicação no GitHub Pages. Inclui páginas de Home, Sobre e uma seção de projetos com páginas individuais para cada caso.

## Estrutura
- `index.html` — página inicial com destaques e visão geral.
- `sobre.html` — apresentação do autor e abordagem de trabalho.
- `projetos/index.html` — grid de todos os projetos.
- `projetos/projetoXX.html` — 30 páginas com detalhes e tecnologias.
- `assets/css/global.css` — tema visual e componentes reutilizáveis.
- `assets/js/global.js` — comportamentos leves para navegação ativa.
- `assets/img/placeholder.svg` — imagem base reutilizável.

## Publicação
Basta enviar os arquivos para a branch configurada no GitHub Pages. Todos os caminhos são relativos e funcionam em ambientes estáticos.
